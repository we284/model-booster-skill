## 阶段 0：审题与建模

1. 重述题目：逐条列出已知条件、所求目标、约束；单位与量纲写明。
2. 先估量级：计算前先估计答案的数量级或合理范围，作为后续 sanity check 的基准。
3. 条件不足或有歧义时：列出各种合理解释分别求解，或先问用户；不允许暗自假设后闷头算。
4. **前提校验**：用户给出的已知条件和"背景事实"分开记——前者按题设接受，后者若是可核查断言（数据、统计、公式）先过台账，可疑先检索核实、核实无果才按 U 标注，不实的前提会毁掉全部推导。

## 阶段 1：分步求解

1. 每步只做一个推导，写明该步用了哪条已知条件或定理，不允许跳步连算。
2. 所有计算一律用代码或工具执行，包括看似简单的四则运算；多步计算写脚本一次算完并打印中间值，不口算。
3. 推导链超过 3 步时，把中间结果代回原条件检验一次再继续，避免错误级联。

## 阶段 2：验证与反例（至少做两项，不许跳过）

- **回代**：把答案代回原题全部条件，逐条验证满足。
- **反例**：尝试构造一个使自己结论不成立的例子；确实构造不出来，才增强置信。
- **特例**：取极端或退化输入（0、1、空、相等、极大值）检验结论是否仍成立。
- **量级对照**：与阶段 0 的估算比较，差一个数量级以上必须找到原因。
- **独立路径**：换一种解法或公式重算，两条路径结果一致才算高置信。

## 攻击测试模板（阶段 2 的具体化，至少跑 3 项，其中 T1、T4 必跑）

| # | 攻击向量 | 具体做法 |
|---|---|---|
| T1 | 极端代入 | 把变量依次换成 0、1、-1、极大、极小、两者相等、空集，看结论是否仍成立 |
| T2 | 单位重算 | 把同一道题换成另一套单位（km/h ↔ m/s、万元 ↔ 元、百分比 ↔ 小数）重算，结果必须一致 |
| T3 | 独立路径 | 换解法：代数法 ↔ 数值法，解析解 ↔ 枚举 / 蒙特卡洛，正推 ↔ 逆推 |
| T4 | 反例搜索 | 用代码在小规模范围内穷举全部情形，找使结论不成立的最小型例子 |
| T5 | 前提松动 | 把"恰好"换成"至少"、"平均"换成"每个"、"定义域全实数"缩成"正数"，结论是否崩 |
| T6 | 数值稳定 | 大数相减、极小值累加、浮点比较处用 `decimal` / `fractions.Fraction` 复算，比较误差 |
| T7 | 量级对照 | 结果与阶段 0 估算差一个数量级以上时，必须找到原因才能继续 |
| T8 | 答问对齐 | 对照阶段 0 写下的所求目标逐字核对结论：回答的是不是题目要的量？单位、量纲、精度符不符合题意？ |

## 计算核验脚本模板

所有多步计算写成一个脚本一次跑完，**打印中间值**，不只打印终值：

```python
from fractions import Fraction
from decimal import Decimal, getcontext
getcontext().prec = 28

def solve_v1(x):
    step1 = Fraction(x) * 3            # 写明这一步用了哪条条件
    step2 = step1 / 7
    print("step1 =", step1, "step2 =", step2)   # 中间值必须落地
    return step2

def solve_v2(x):                       # 独立路径：换成小数近似
    return Decimal(x) * 3 / 7

x = 5
a, b = solve_v1(x), solve_v2(x)
print("v1 =", float(a), "v2 =", float(b))
assert abs(float(a) - float(b)) < 1e-9, "两条路径不一致，停下查因"
```

脚本要能直接跑（`python3 check.py`），并在交付时贴出真实输出。

## 阶段 3：结论与置信度

1. **答问对齐**：结论回答的必须是阶段 0 写下的所求目标，单位、量纲、精度与题意一致——算出的是容易算的量而不是所问的量，等于没算对。
2. 结论 = 数值/判断 + 适用条件 + 验证方式（实际用了阶段 2 的哪几项）。
3. 置信度分级并显式标注：已验证（阶段 2 通过至少两项）/ 部分验证（只完成一项）/ 未验证（仅推导）。
4. 存在多种合理解时全部列出，各自的前提假设写清楚，不擅自替用户选择。
5. 未完成的验证显式标注"未验证"及原因，禁止用流畅措辞掩盖。

## 推理高频缺陷清单（求解和验证时主动排查）

- 偷换条件：把"至少"当"恰好"、把"平均"当"每个"、忽略定义域和前提
- 默认整数或正数：实际可取小数、负数、零
- 单位混乱：公里/小时与米/秒混算；百分比与百分点混用
- 口算错误：多步算术不借助工具，中间值不落地
- 以偏概全：一个例子成立就当普遍结论；归纳代替证明
- 循环论证：用待证的结论当推理前提
- 答案不回代：算出结果直接交付，不满足原题约束
- 求非所问：答的是容易算的量而非题目所问；单位、精度与题意不符
- 数据分析特有问题：相关当因果、忽略样本量、被平均数掩盖分布、幸存者偏差
